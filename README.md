# CodeAlpha Portfolio

A responsive personal portfolio website built to showcase my skills, projects, education and contact details.

**Live demo:** https://codealphaownportfolio.vercel.app

## About

This is my personal portfolio, built as part of the CodeAlpha Frontend Development Internship (Task: Build Your Own Portfolio Site). It presents who I am, what I work with and what I have built, in a clean dark theme.

## Sections

- **Home:** introduction with call-to-action buttons
- **About:** short bio and key highlights
- **Skills:** technologies I am learning and using
- **Projects:** featured projects with tech stack tags
- **Achievements and Certifications:** problem solving, hackathons and community
- **Education:** academic journey
- **Contact:** email, LinkedIn and GitHub links
- **Download CV:** one-click resume download

## Features

- Fully responsive layout (desktop, tablet and mobile)
- Mobile hamburger navigation menu
- Hover effects and transitions on cards, buttons and links
- Sticky navbar with in-page section links
- Downloadable resume (PDF)

## Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (vanilla)

## Run Locally

1. Clone the repository:
````bash
   git clone https://github.com/AryanJaiswalDev/CodeAlpha_Portfolio.git
````
2. Open the folder and double-click `index.html`, or use the Live Server extension in VS Code.
